# CALDER

[中文](README.md) | [English](README_EN.md)

CALDER 是一个用于 AI 生成文本检测的多特征融合模型。用户只需提供文本和标签；语义、token 概率、对齐印记、文档统计和压缩/码长特征由程序内部自动提取、对齐和缓存。

CALDER 不直接把 LAPD、LastDE、DetectGPT 等 training-free detector 的最终分数作为模型输入。

## 1. 安装

```bash
git clone https://github.com/try2love/CALDER.git
cd CALDER

python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
```

首次运行会从 Hugging Face 下载冻结 observer 模型；模型不包含在本仓库中。Llama-2 需要先在 Hugging Face 页面获取访问权限，然后登录：

```bash
hf auth login
```

Hugging Face 官方文档：<https://huggingface.co/docs/huggingface_hub/guides/cli>

## 2. 准备训练数据

训练集和开发集使用 JSONL 或 CSV。每条样本只需要文本和标签。

JSONL 示例：

```jsonl
{"sample_id":"train-0001","content":"This article was written by a person.","label":0}
{"sample_id":"train-0002","content":"This passage was generated by an AI system.","label":1}
```

也可以使用 `text` 代替 `content`：

```jsonl
{"text":"Human-written text...","label":"human"}
{"text":"AI-generated text...","label":"AI"}
```

标签方向固定为：

- human = `0`
- AI/machine = `1`

`sample_id` 可选；不提供时程序会自动生成。训练集和开发集都必须包含两个类别。

## 3. 一条 Python 命令启动训练

```bash
python -m benchmark_fusion train \
  --train data/train.jsonl \
  --dev data/dev.jsonl \
  --output outputs/calder_run
```

这条命令会自动完成：

1. 读取和校验 `content/text + label`；
2. 加载所有冻结 observer；
3. 对文本最多取前 1024 tokens，右侧截断；
4. 提取并聚合八个 CALDER 输入 tensor；
5. 将中间特征缓存在 `outputs/calder_run/.cache/`；
6. 用训练集统计做 z-score；
7. 训练五分支融合模型；
8. 使用开发集 AUROC 早停；
9. 只保留最佳模型 `outputs/calder_run/calder_model.pt`；
10. 在开发集上固定后续判别阈值。

默认训练参数：seed 42、learning rate `3e-4`、batch size 128、hidden size 128、adaptive gate、最多 20 epochs、patience 4。

### 指定 GPU

推荐用两张 GPU 分别放置 base/aligned observer：

```bash
python -m benchmark_fusion train \
  --train data/train.jsonl \
  --dev data/dev.jsonl \
  --output outputs/calder_run \
  --devices cuda:0,cuda:1 \
  --train-device cuda:0
```

只有一张 GPU 时，可以将 aligned observer 放在 CPU，但特征提取会明显变慢：

```bash
python -m benchmark_fusion train \
  --train data/train.jsonl --dev data/dev.jsonl \
  --output outputs/calder_run \
  --devices cuda:0,cpu --train-device cuda:0
```

## 4. 直接输入纯文本进行判别

```bash
python -m benchmark_fusion predict \
  --model outputs/calder_run/calder_model.pt \
  --text "Paste the text to be detected here."
```

程序会自动使用训练时记录的 observer 配置提取特征，然后输出：

```json
{"sample_id":"input-0001","ai_score":1.27,"ai_probability":0.7807,"prediction":"AI"}
```

- `ai_score`：AI-positive 原始 logit，越大越像 AI 文本；
- `ai_probability`：sigmoid 值，用于直观阅读；
- `prediction`：使用训练时在开发集上固定的阈值生成。

### 判别一个 TXT 文件

```bash
python -m benchmark_fusion predict \
  --model outputs/calder_run/calder_model.pt \
  --text-file article.txt \
  --output predictions.jsonl
```

### 批量判别 JSONL/CSV

```bash
python -m benchmark_fusion predict \
  --model outputs/calder_run/calder_model.pt \
  --input data/to_detect.jsonl \
  --output predictions.jsonl
```

批量输入只需 `text` 或 `content`，不需要 `label`。

## 5. 默认 observer

| 用途 | 模型 |
|---|---|
| 语义 span | `answerdotai/ModernBERT-base` |
| 概率/对齐 | `meta-llama/Llama-2-7b-hf` + `meta-llama/Llama-2-7b-chat-hf` |
| 概率/对齐 | `tiiuae/falcon-7b` + `tiiuae/falcon-7b-instruct` |
| 文档概率/码长 | `openai-community/gpt2` |
| 模型尺度/码长 | `openai-community/gpt2-large` |

模型 ID 和版本会写入 `calder_model.pt` 和 `observer_config.json`。如需使用本地模型路径，可以复制并修改 observer config，然后传入：

```bash
python -m benchmark_fusion train ... --observer-config my_observers.json --local-files-only
```

## 6. 显存和速度说明

CALDER 融合网络本身很小，但完整特征提取需要运行多个冻结 observer。默认配置推荐两张 24 GB 或更大显存的 GPU；纯 CPU 或单 GPU + CPU 可运行，但会较慢。程序按 observer 阶段顺序加载和释放模型，不会同时把全部六个 causal observer 留在显存中。

## 7. 输入 schema 和模型结构

内部特征 tensor 定义见 [INPUT_SCHEMA.md](INPUT_SCHEMA.md)。这些 tensor 全部由文本提取管线生成，普通用户不需要自行制作 NPZ。

标准代码入口：

- `src/benchmark_fusion/text_features.py`：原始文本特征提取与聚合；
- `src/benchmark_fusion/calder_model.py`：五分支 CALDER 结构；
- `src/benchmark_fusion/text_cli.py`：训练和纯文本判别命令；
- `scripts/`：论文冻结协议的低层可追溯入口。

## 8. 测试

```bash
python -m unittest discover -s tests -v
```

测试不会下载大模型；原始文本流程使用可控 fake observer 验证数据读取、内部特征传递、训练、模型加载和纯文本判别。

## 9. 开源边界

仓库包含完整的原始文本特征提取、CALDER 训练和推理代码，但不包含：

- 数据集或论文数据划分；
- 任何预训练 observer 权重；
- 训练后 CALDER checkpoint；
- 预测、实验结果、看板或论文源文件。

外部 observer 的访问权限和许可证由各模型发布方单独管理，不受本项目源代码许可证覆盖。
